# HOPE JOURNEY — رحلة أمل

منصة إلكترونية لمرضى السرطان في ليبيا: تطبيق للمرضى، بوابة للجمعيات والمستشفيات والمتبرعين، لوحة إدارة، وموقع تعريفي — تعمل محليًا على جهاز المستخدم دون أي خادم سحابي.

هذا المستودع مخصص لصفحة التحميل العامة وملفات الإصدارات فقط. منصة التشغيل وقاعدة بيانات المرضى **ليست** هنا.

الموقع العام للمنصة نفسه يُقدَّم من خادم المنصة على العنوان العام الذي يظهر عند تشغيل «ابدأ-النشر-العام.bat»، ويحتوي صفحة التطبيقات في `/site/install.html`. هذه الصفحة هنا بديل ثابت للتحميل عند عدم توفر الخادم.

## التحميل

- صفحة التحميل: https://sadrmdan976-hub.github.io/hope-journey/
- ويندوز (يشغّل المنصة كاملة): [HOPE-JOURNEY-Windows-1.1.zip](../../releases/latest/download/HOPE-JOURNEY-Windows-1.1.zip)
- أندرويد (تطبيق الهاتف): [HOPE-JOURNEY-Android-1.2.apk](../../releases/latest/download/HOPE-JOURNEY-Android-1.2.apk)

## الإصدارات 1.1 (ويندوز) و1.2 (أندرويد) — 26 نوفمبر 2026

- تطبيق ويندوز مستقل (64-bit) يشغّل المنصة بضغطة واحدة.
- تطبيق أندرويد 1.2 (7.0+) يعمل على أي شبكة عبر رابط ثابت يتحدّث تلقائيًا: https://sadrmdan976-hub.github.io/hj/
- صفحة تثبيت داخل الموقع العام نفسه مع بصمات SHA-256 وخطوات التثبيت.
- بياناتك تبقى على جهازك؛ الحزم لا تحتوي أي قاعدة بيانات أو إعدادات.

## التحقق من السلامة

بصمات SHA-256 منشورة في صفحة التحميل. قارنها بعد التنزيل:

```
sha256sum HOPE-JOURNEY-Windows-1.1.zip
sha256sum HOPE-JOURNEY-Android-1.2.apk
```

## المتطلبات

- Windows 10/11 (64-bit) — لا يحتاج Python.
- Android 7.0+ — أي شبكة (بيانات الجوال أو واي فاي) أو نفس شبكة الخادم المحلية.
